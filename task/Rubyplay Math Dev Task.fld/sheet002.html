Create game simulation in java. Simulate 10M rounds to check and prove Return to player (RTP) and to calculate Standard Deviation.
It is a slot game with predefined reels and symbols on the reels.
Details of the game configuration can be found on “Task math model” sheet.
Stop reels. To stop reels, draw a random number between 0 and reel length for each reel, and evaluate the reel picture based on the random indexes.
After stopping the reels, determine the reel picture and evaluate wins.
Game is on 3x3 matrix, and paying on 5 paylines only 3 of a kind of the same symbol.
Each round costs 10, and payout will be determined based on reel picture outcome evaluation.
RTP is sum of all win amounts from all game rounds, divided by total bet amount (sum of all bets from all game rounds)
