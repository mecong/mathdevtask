Base Game
The game Fruit slot game with 3 row 3 reels. There are 3 reels in the base game. A predetermined set of symbols that are used for creating the reel picture.
The game payline mechanic – 5 paylines Spin the reels, draw a random number between 0 and reel length for each reel, and evaluate the reel picture based on the random indexes.
This means that game will pay for 3 of a kind of the same symbol on a payline.
Round costs is 10 credits, and each paying line will award payout according to the paytable.
Game has one wild symbol W1, acting like joker – that substitute for all symbols except scatter symbol.
